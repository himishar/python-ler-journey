Day 3 — Python Strings (Slicing, Methods & Data Cleaning)

Completed on 3 September 2026
COMPLETED

Mastered complete string operations: indexing, negative slicing & stepping, immutability, built-in string methods (split, join, strip, replace), formatting with f-strings, and real-world ETL text sanitation.

View Day 3 Strings Revision Notes (Slicing, Methods, Cleaning...)
Topics Covered & Understood
  • String Fundamentals & Immutability: Strings as ordered sequences, zero-based indexing, why strings cannot be modified in-place
  • Slicing & Stepping: Positive/negative indices, range slicing [start:stop:step], and string reversal [::-1]
  • Trimming & Sanitization: strip(), lstrip(), rstrip() to clean unwanted whitespaces, tabs, and newline characters
  • Case & Format Adjustments: lower(), upper(), title(), capitalize() for uniform data pipelines
  • Search & Verification: find(), count(), startswith(), endswith(), and the in keyword
  • Splitting & Joining: split() (delimiter to list), rsplit(), and "".join() (list to clean string)
  • Replacement & f-Strings: replace() for masking/standardizing, plus modern expressions via f"{var}"

  • Status: Successfully completed Day 3 checklist ✅
🧠 Day 3 Key Takeaways

Raw incoming data from APIs, web scraping, and log files is almost always messy, unformatted text. Mastering string methods like strip(), replace(), split(), and join() allows converting unstructured strings into clean, validated, and standard records for downstream database storage.
