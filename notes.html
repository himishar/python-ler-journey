1. Python Variables & id() Memory Address

Named memory container used to store values.
💡 Definition: Variable ek storage label hota hai jo memory me kisi value ko point karta hai. Python dynamically typed language hai, isliye datatype declare nahi karna padta.
Python id() Function: Memory Identity Check

id(variable_name) har object ka unique memory address (integer) return karta hai jahan RAM me wo value exist karti hai.

# Agar do variables same value point kar rahe hain toh dono ka id() same hoga:
a = 100
b = 100
print(id(a))  # Output: 140735284931232 (Memory location)
print(id(b))  # Output: 140735284931232 (Same memory address!)
Naming Rules (Short & Clear):
Letter (a-z) ya Underscore (_) se start hona chahiye.
Number se start nahi ho sakta (e.g. 1name ❌).
Case-sensitive hota hai (age aur Age alag hain).
Special symbols (@, $, -, %) strictly not allowed.

5. Type Casting (टाइप कास्टिंग)

Converting one data type into another.
💡 Definition & Types:
  • Implicit (Automatic): Python khud chhoti type ko badi type me convert karta hai (e.g. 5 + 2.5 = 7.5).
  • Explicit (Manual): Hum functions se manually convert karte hain: int(), float(), str(), bool().
Float to Int Conversion Rule:

Haan, int(99.85) se float int me convert ho jata hai (result: 99). Python decimal ke baad ke digits ko hata (truncate) deta hai, round-off nahi karta.

int(4.99) $\rightarrow$ 4  |  int(4.1) $\rightarrow$ 4
Type Casting Traps: Kya Direct Convert NAHI Hota?
Yeh 4 cases me Python direct convert nahi karta aur Error deta hai:
1. Decimal String to Int ValueError
Agar string me decimal point hai jaise int("45.67") toh direct int nahi banega.
Solution int(float("45.67")) → 45
2. Alphabetic Text to Number ValueError
Letters ya alphabets jaise int("Himanshu") ya float("abc") convert nahi ho sakte.
Strings ke andar valid digits (0-9) hona anivarya hai.
3. Empty String ya Spaces ValueError
Khali string int("") ya spaces int(" ") direct convert karne par fail ho jaati hai.
4. NoneType to Number TypeError
Null value int(None) ko seedha integer ya float me cast nahi kar sakte.
Real Example 1: Birth Year to Age Calculation (str to int)

# input() string deta hai, int() se number banaya

6. Python Functions (फ़ंक्शन्स)

Reusable block of organized code designed to perform a specific task.
💡 Definition & Core Purpose: Function ek reusable code block hota hai jise hum def keyword se banate hain. Iska main principle hota hai DRY (Don't Repeat Yourself) — ek baar likho aur dynamically inputs pass karke multiple times call karo.
Types of Functions
  • Built-in: Pre-installed jaise print(), len(), type(), sum(), id().
  • User-Defined: Jo programmer khud def keyword se define karta hai.
Parameters vs Arguments
  • Parameters: Function definition ke time wale placeholders (def f(x, y):).
  • Arguments: Function call karte waqt pass ki gayi actual values (f(10, 20)).
4 Ways to Pass Arguments
  • Positional: Order ke according pass hote hain.
  • Keyword: Name specify karke (rate=0.18).
  • Default: Fallback parameters (def db(port=3306):).
  • *args & **kwargs: Dynamic multiple inputs lene ke liye.
Return vs Non-Return
  • Return (return): Result wapas deta hai jisko variable me capture karke aage use kar sakte hain.
  • Non-Return: Sirf print karta hai aur memory me None return karta hai.
Scope of Variables (Local vs Global Scope):
1. Local Scope: Function ke andar banta hai aur bahar inaccessible hota hai (NameError).
2. Global Scope: Function ke bahar banta hai aur pure script me accessible hota hai. Modify karne ke liye global keyword lagta hai.
Real Example 1: ETL Pipeline Data Sanitizer & Currency Formatter
etl_cleaner.py 
def clean_and_format_price(raw_price_str, currency_symbol="Rs."):
    # Local variable: sirf is function ke andar access hoga
    cleaned_number = float(raw_price_str.strip().replace(",", ""))
    formatted_output = f"{currency_symbol} {cleaned_number:,.2f}"
    return formatted_output   # Output wapas return kiya

# Calling function with default currency (Positional Argument)
item1 = clean_and_format_price(" 14,500.50 ")

# Calling with custom currency symbol (Keyword Argument)
item2 = clean_and_format_price("299.99", currency_symbol="$")

print(f"Processed Record 1: {item1}")
print(f"Processed Record 2: {item2}")
Output:
Processed Record 1: Rs. 14,500.50
Processed Record 2: $ 299.99
Real Example 2: E-Commerce Bill Engine & Global Sales Counter (Scope & Return)
checkout_engine.py 
# Global variable: Pure application ka total revenue track karne ke liye
total_store_revenue = 0.0

def calculate_order_bill(cart_items_count, item_rate, discount_percent=5.0):
    global total_store_revenue  # Global variable update karne ki permission
    
    subtotal = cart_items_count * item_rate
    discount_amount = (subtotal * discount_percent) / 100
    final_payable = subtotal - discount_amount
    
    total_store_revenue += final_payable  # Global update
    return final_payable                  # Return calculated amount

order1 = calculate_order_bill(cart_items_count=4, item_rate=500)
order2 = calculate_order_bill(cart_items_count=2, item_rate=1200, discount_percent=10.0)

print(f"Order 1: Rs. {order1:.2f} | Order 2: Rs. {order2:.2f}")
print(f"Total Store Revenue: Rs. {total_store_revenue:.2f}")
Output:
Order 1: Rs. 1900.00 | Order 2: Rs. 2160.00
Total Store Revenue: Rs. 4060.00

7. Python Strings (स्ट्रिंग्स), Indexing, Slicing & All Methods

Text manipulation, slicing step rules, and ETL text cleaning methods.
💡 Definition & Immutability: String characters ka sequence hota hai jo single (' ') ya double (" ") quotes me likha jata hai.
⚠️ Core Rule: Python Strings Immutable hoti hain — yaani ek baar banne ke baad inke kisi character ko direct change nahi kiya ja sakta (e.g. text[0] = 'A' ❌ TypeError deta hai).
String Indexing Matrix (Positive & Negative Indexing):
Characters P Y T H O N
Positive Index (Left to Right) 0 1 2 3 4 5
Negative Index (Right to Left) -6 -5 -4 -3 -2 -1
String Slicing & Stepping Formula: string[start : stop : step]
1. start: Starting index (Inclusive - yahan se shuru karega).
2. stop: Ending index (Exclusive - is index se 1 pehle ruk jayega).
3. step: Kitne jump lene hain (Default 1, negative se reverse).
text = "DATAENGINEER"
text[0:4]      # 'DATA' (Index 0 to 3)
text[4:]       # 'ENGINEER' (Index 4 se end tak)
text[::2]      # 'DTEGNE' (Har 2nd character jump)
text[::-1]     # 'REENIGNEATAD' (Pure string ko REVERSE karna)
