1. Python Variables (वैरिएबल्स)

Named memory container used to store values.
💡 Definition: Variable ek storage box ki tarah hota hai jisme hum value (number, text, etc.) store karte hain taaki aage code me reuse kar sakein. Python dynamically typed language hai, isliye datatype declare nahi karna padta.
Naming Rules (Short & Clear):
Letter (a-z) ya Underscore (_) se start hona chahiye.
Number se start nahi ho sakta (e.g. 1name ❌).
Case-sensitive hota hai (age aur Age alag hain).
Special symbols (@, $, -, %) strictly not allowed.
Real Example 1: E-Commerce Product Details
product_info.py 
# Product details store karne ke liye variables
product_name = "Wireless Gaming Mouse"
product_price = 1299.50
stock_quantity = 45
is_in_stock = True

print(f"Product: {product_name}")
print(f"Price: Rs. {product_price} | Available Units: {stock_quantity}")
Output: Product: Wireless Gaming Mouse
Price: Rs. 1299.5 | Available Units: 45
Real Example 2: Employee Payroll System
payroll_variables.py 
# Employee salary calculation variables
emp_id = "DE_102"
base_salary = 65000
bonus = 7500
total_payout = base_salary + bonus

print(f"Employee ID: {emp_id} -> Total Salary: Rs. {total_payout}")
Output: Employee ID: DE_102 -> Total Salary: Rs. 72500

2. Python Data Types (डेटा टाइप्स)

Type of data stored inside a variable.
💡 Core Data Types:
  • int: Poore numbers (e.g. 25, -10)
  • float: Decimal wale numbers (e.g. 99.99, 3.14)
  • str: Text ya strings jo quotes me ho (e.g. "Himanshu")
  • bool: Sirf True ya False
  • NoneType: Jab value empty/null ho (None)
Real Example 1: User Profile Record Check
datatypes_check.py 
user_id = 101               # int
user_name = "Himanshu"      # str
account_balance = 4520.75   # float
is_premium = True           # bool
referral_code = None        # NoneType

# type() function se datatype check karna
print(type(user_id))          # <class 'int'>
print(type(user_name))        # <class 'str'>
print(type(account_balance))  # <class 'float'>
print(type(is_premium))       # <class 'bool'>
print(type(referral_code))    # <class 'NoneType'>
Output: <class 'int'> | <class 'str'> | <class 'float'> | <class 'bool'> | <class 'NoneType'>
Real Example 2: IoT Weather Sensor Reading
weather_sensor.py 
city = "Delhi"           # str
temp_celsius = 32.4      # float
humidity = 65            # int (percentage)
is_raining = False       # bool

print(f"[{city}] Temp: {temp_celsius}°C, Humidity: {humidity}%, Rain: {is_raining}")
Output: [Delhi] Temp: 32.4°C, Humidity: 65%, Rain: False

3. Python Operators (ऑपरेटर्स)

Symbols used to perform operations on values & variables.
💡 Main Operator Categories:
1. Arithmetic: +, -, *, / (float division), // (floor division), % (remainder), ** (power)
2. Comparison: ==, !=, >, <, >=, <= (True/False)
3. Logical: and, or, not
4. Assignment: =, +=, -=, *=
Real Example 1: Grocery Shopping Bill & Discount
bill_calculation.py 
item_price = 450
quantity = 3
gst_rate = 0.18        # 18% GST

# Arithmetic operators
subtotal = item_price * quantity        # Multiplication
tax_amount = subtotal * gst_rate
final_bill = subtotal + tax_amount      # Addition

# Comparison operator: Check discount eligibility
is_eligible_discount = final_bill >= 1000

print(f"Total Bill: Rs. {final_bill:.2f}")
print(f"Eligible for VIP Coupon: {is_eligible_discount}")
Output: Total Bill: Rs. 1593.00
Eligible for VIP Coupon: True
Real Example 2: Loan Approval Eligibility (Logical Operators)
loan_check.py 
monthly_income = 48000
credit_score = 760
has_active_default = False

# and / not operators combine conditions
is_loan_approved = (monthly_income >= 30000) and (credit_score > 700) and (not has_active_default)

print(f"Loan Approved Status: {is_loan_approved}")
Output: Loan Approved Status: True

5. Type Casting (टाइप कास्टिंग)

Converting one data type into another.
💡 Definition & Types:
  • Implicit (Automatic): Python khud chhoti type ko badi type me convert karta hai (e.g. 5 + 2.5 = 7.5).
  • Explicit (Manual): Hum functions se manually convert karte hain: int(), float(), str(), bool().
Float to Int Conversion Rule:

Haan, int(99.85) se float int me convert ho jata hai (result: 99). Python decimal ke baad ke digits ko hata (truncate) deta hai, round-off nahi karta.

int(4.99) $\rightarrow$ 4  |  int(4.1) $\rightarrow$ 4
Type Casting Traps: Kya Direct Convert NAHI Hota?
Yeh 4 cases me Python direct convert nahi karta aur Error deta hai:
1. Decimal String to Int ValueError
Agar string me decimal point hai jaise int("45.67") toh direct int nahi banega.
Solution int(float("45.67")) → 45
2. Alphabetic Text to Number ValueError
Letters ya alphabets jaise int("Himanshu") ya float("abc") convert nahi ho sakte.
Strings ke andar valid digits (0-9) hona anivarya hai.
3. Empty String ya Spaces ValueError
Khali string int("") ya spaces int(" ") direct convert karne par fail ho jaati hai.
4. NoneType to Number TypeError
Null value int(None) ko seedha integer ya float me cast nahi kar sakte.
Real Example 1: Birth Year to Age Calculation (str to int)
age_calculator.py 
# input() string deta hai, int() se number banaya
birth_year_input = input("Enter birth year: ")
birth_year = int(birth_year_input)   # Explicit Casting: '2002' -> 2002

current_year = 2026
age = current_year - birth_year

print(f"Calculated Age: {age} years old")
Demo:
> Enter birth year: 2002
> Calculated Age: 24 years old
Real Example 2: Salary Increment with Decimal Rate (str to float)
salary_appraisal.py 
# User se salary aur hike percentage lena
current_salary = float(input("Enter current salary: "))     # String to float
hike_percentage = float(input("Enter appraisal % (e.g. 12.5): "))

# Calculations with converted float numbers
increment_amount = (current_salary * hike_percentage) / 100
new_salary = current_salary + increment_amount

print(f"Increment: Rs. {increment_amount:.2f}")
print(f"Revised Salary: Rs. {new_salary:.2f}")
Demo:
> Enter current salary: 50000
> Enter appraisal % (e.g. 12.5): 12.5
> Increment: Rs. 6250.00
> Revised Salary: Rs. 56250.00
